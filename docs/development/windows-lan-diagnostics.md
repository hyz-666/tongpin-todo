# Windows LAN 同步诊断

## 诊断分类

平台适配器把问题归类为以下类别，不做任何防火墙规则修改：

| 分类 | 含义 | 建议 |
|------|------|------|
| `NoLan` | 无活动局域网接口 | 检查 Wi-Fi/网线是否连接 |
| `NoCandidates` | 有网络但没发现任何候选 | 确认另一台设备在同一网段并运行中 |
| `CandidateUnreachable` | 发现候选但 TCP 连不上 | 检查防火墙是否阻止入站 5353/监听端口 |
| `FirewallLikely` | 连接被 RST/超时，疑似防火墙 | 用户可自行在 Windows 防火墙中放行应用 |
| `AuthenticationFailed` | Noise 握手/SAS 不匹配 | 重新配对 |
| `Revoked` | 对端已被撤销 | 需要重新配对 |
| `Incompatible` | 协议 major/schema 不兼容 | 升级到同一版本 |
| `ApIsolation` | 发现但设备间互不可达 | 检查路由器是否开启 AP 隔离 |

## 用户可操作的检查

### Windows 防火墙
1. 打开「Windows 安全中心 → 防火墙和网络保护 → 允许应用通过防火墙」。
2. 确保应用已勾选「专用网络」。
3. 应用首次监听时会弹出允许对话框——不要点「取消」。

### AP 隔离（客户端隔离）
- 登录路由器管理页，找到「无线设置 → AP 隔离 / 客户端隔离」，关闭。
- 开启时，同一 Wi-Fi 下的设备之间无法直接通信（表现：能发现但永远连不上）。

### VPN / 虚拟网卡
- 部分 VPN 会劫持局域网路由或改默认网关；断开 VPN 后再试。
- 多个虚拟网卡（WSL/Hyper-V）会让 mDNS 广播到错误接口——只保留实际使用的接口。

### 重试
- 网络变化后应用会自动重新发现（0–2 秒抖动）。
- 用户驱动的「重试」按钮立即触发一次尝试，不保证同一 SSID 可达。

## 隐私边界

mDNS/TXT 记录只发布：协议 major、能力位、监听端口、轮换提示（HMAC 16 字节）。
绝不发布：任务内容、组 ID、稳定设备 ID、友好名、公钥、SAS 或原始发现密钥。
