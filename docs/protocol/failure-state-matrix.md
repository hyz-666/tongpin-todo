# Failure State Matrix

## 状态定义

### 副本状态（ReplicaState）

| 状态 | 含义 | 用户可见提示 |
|------|------|-------------|
| `Ready` | 正常读写 | 无提示 |
| `ReadOnlyLowSpace` | 磁盘空间低于阈值 | 「空间不足，暂只读」 |
| `Recovering` | 正在恢复/重建 | 「正在恢复…」，**不显示空副本** |
| `Unavailable` | 存储不可用 | 「无法访问数据」 |

### 每 peer 连接状态（SessionState）

`Offline → Dialing → Handshaking → Syncing`，失败分支 `Backoff / Incompatible / Revoked`。

### 调度决策（SyncDecision）

`Sync / Pause（低空间）/ Block（不兼容）/ Stop（已撤销）/ Defer（系统延迟或退出中）`。

## 故障矩阵

| 故障 | 检测 | 行为 | 数据风险 |
|------|------|------|---------|
| 丢包 | 传输层 | 检查点重传 | 无 |
| 重复帧 | 操作 ID 去重 | 幂等忽略 | 无 |
| 乱序交付 | 前沿/缺口 | 按 HLC 确定性合并 | 无 |
| 半帧（截断） | 长度前缀校验 | 拒绝并重传 | 无 |
| 损坏帧 | Noise 认证标签 | 拒绝并重传 | 无 |
| ACK 丢失 | 超时 | 从检查点重发 | 无（重放安全） |
| 连接中断 | 心跳 30s | 保留检查点，退避重连 | 无 |
| 新 IP / 网络切换 | generation 递增 | 丢弃过期候选与 socket | 无 |
| 时钟回拨 / 偏斜 | HLC 单调递增 | 逻辑时钟前进 | 无 |
| 应用/快照/重建中被杀 | 事务原子性 | 重启后从检查点恢复 | 无 |
| 磁盘空间不足 | 健康检查 | 转只读 + 迟滞恢复 | 无 |
| 数据库损坏 | 打开失败 | 隔离损坏文件 | 需从备份/peer 恢复 |
| 密钥丢失 | 打开失败 | 拒绝访问（不降级） | 数据不可读 |
| 协议不兼容 | HELLO 协商 | `Incompatible`，不应用数据 | 无 |
| 对端被撤销 | 成员图 | 立即 `Revoked` 停止 | 无 |
| 对端远低于保留水位 | 版本摘要 | 收到可合并快照 | 无 |

## 关键不变量

1. **ACK 只在提交后推进**——任何阶段失败都不推进，重放始终安全。
2. **到达顺序无关**——不存在"必须按某顺序到达"的规则，合并按 HLC 确定性进行。
3. **撤销后重建是确定性的**——截止点之前保留、之后丢弃，并发有效操作保留。
4. **压缩永不超前于水位线**——必须被固定的已验证快照覆盖。
5. **墓碑回收需要全员 ACK**——长离线的未撤销成员阻塞回收。

## 收敛验证

- 三副本分区 → 各自编辑 → 任意顺序重连 → 状态一致（10,000 操作确定性套件）。
- 敌对网络：伪造 mDNS、密钥替换、SAS 不匹配/过期/重放、错误组/纪元/签名、撤销重连、帧重放/坏标签、畸形/超大 CBOR、未知必需特性——**断言零未授权变更**。
- 失败种子命名保存为回归用例（`crates/todo-core/tests/regressions/`）。
