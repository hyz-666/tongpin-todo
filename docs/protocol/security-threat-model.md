# Security Threat Model

## 资产

| 资产 | 机密性 | 完整性 |
|------|--------|--------|
| 任务内容（标题/备注/标签） | 高 | 高 |
| 成员身份与公钥绑定 | 低 | 极高 |
| 设备私钥（Ed25519 签名 / X25519 静态） | 极高 | — |
| 发现密钥（discovery secret） | 中 | 高 |
| 操作历史与因果元数据 | 低 | 极高 |

## 信任边界

1. **平台适配层（不可信）**：mDNS 候选、IP 地址、服务实例名全部不可信，只作端点提示。
2. **Noise 会话（已认证）**：XX 用于首次配对，IK 用于已知成员重连（pinned 静态公钥）。
3. **成员图（授权）**：只有成员图中活跃成员的签名操作才被接受。

## 威胁与缓解

| 威胁 | 缓解 |
|------|------|
| 伪造 mDNS 广播 | 发现提示只是 HMAC 衍生值，不授信任；真实信任来自 Noise + 成员签名 |
| 中间人（首次配对） | Noise XX + 六位 SAS 双方确认；SAS 绑定握手 transcript |
| 中间人（重连） | Noise IK 使用 pinned 成员静态公钥 |
| 密钥替换 | `IdentityBinding` 把 DeviceId/签名公钥/Noise 公钥绑定进成员事件 |
| 撤销设备重连 | 成员图中 `revoked` 集合；撤销后轮换 discovery secret |
| 重放操作 | 操作 ID（device + sequence）去重；前沿与缺口追踪 |
| 帧重放 / 错序 | Noise 传输序列号每方向从 0 单调，不回绕 |
| 未授权写入 | 操作签名在任何存储访问**之前**验证，返回类型化原因 |
| 畸形/超大 CBOR | 定长读取 + 严格解码，拒绝不定长/额外字段/尾随字节 |
| 拒绝服务 | 帧 64 KiB / chunk 512 KiB / 32 并发块 / 8 MiB 密文上限 |

## 被盗或离线设备

- 被盗设备在撤销前可以读取它已同步的数据——**无法远程擦除**。
- 撤销后：会话立即终止，discovery secret 轮换（加密分发给剩余成员），因果截止点之后的操作被重建时丢弃。
- 撤销有传播延迟：在成员图更新前，被撤销设备仍可能收到有限的数据。

## 撤销延迟与因果截止

撤销事件携带 `causal_cutoff`。重建时：
- 截止点**之前**的效果保留；
- 截止点**之后**的效果丢弃；
- 并发的有效 peer 操作保留。

## 密钥存储边界

- 私钥由操作系统凭据/密钥库保管，永不出库。
- 备份快照排除私钥与数据库密钥。
- 诊断导出经过脱敏，不含任务内容、密钥、SAS 或完整指纹。

## 明确的能力缺失

- **无远程擦除**：设备丢失无法远程清除其已同步副本。
- **无云恢复**：没有服务器，也没有云端兜底；恢复依赖其它成员的快照。
- **无前向保密的历史保护**：撤销前已泄露的数据无法追回。
